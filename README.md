# 麦算 maisuan

**在麦当劳吃饱、吃好、还能瘦的减脂省钱搭餐小帮手。**

输入身高体重，它从麦当劳**真实在售菜单**里现场搭出：热量达标、蛋白充足、价格最低的一餐。营养、菜单、价格全部来自麦当劳官方 MCP 实时数据，不是拍脑袋的静态表。

![demo](docs/demo.gif)

## 为什么做这个

- 年轻人越来越注重健康，但减脂不等于告别麦当劳——关键是**会选**
- 年轻人也不富裕——同样的营养，能省则省
- 麦算把两条线拧成一个指标：**用有限的钱，买到热量最低、蛋白质最高、最顶饱的一餐**

## 三种用法

### 1. 网页界面（推荐）

```bash
node proxy/server.mjs        # 只监听 127.0.0.1:8321
# 浏览器打开 http://127.0.0.1:8321
```

填身高体重 → 出 Top3 推荐卡片（官方商品图、热量/蛋白/钠进度条、实付估价），支持「饱腹优先 / 便宜优先」一键切换。

### 2. WorkBuddy Skill

在 WorkBuddy 对话里说「帮我搭一餐」，Skill 会引导你给出身高体重并调用引擎。见 [SKILL.md](SKILL.md)。

### 3. 命令行

```bash
node cli.js --height 170 --weight 70 --budget 25 --cheap
```

## 它是怎么算出来的

1. **目标**：Mifflin-St Jeor 公式算 TDEE → 减脂目标赤字 20%（封顶 500 kcal）→ 单餐按 35% 分配；蛋白质底线 1.6 g/kg（减脂保肌通用共识）
2. **数据**：菜单/商品图/选配来自 `query-meals` + `query-meal-detail`，营养来自 `list-nutrition-foods`，价格来自 `calculate-price`——全部麦当劳官方 MCP 实时拉取，详见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)
3. **搭配**：主食 × 配餐 × 饮品全组合枚举，硬约束（热量/蛋白/预算）过滤后，按饱腹分（蛋白主导 + 低能量密度 - 高钠）或价格排序
4. **诚实提示**：钠超每日建议 60% 会告诉你「有点咸」——它不会为了推荐而隐瞒

## 安装与运行

前置：Node.js ≥ 20，麦当劳 MCP Token（[open.mcd.cn](https://open.mcd.cn) 控制台申请）。

```bash
export MCD_TOKEN=<你的token>     # Windows: set MCD_TOKEN=<token>
# 首次：拉取菜单与价格缓存（约 1 分钟，35 次 MCP 调用）
node scripts/build-menu-cache.mjs
node scripts/build-price-cache.mjs
# 自检（15 项断言，全过退出码为 0）
node scripts/self-check.mjs
```

## 目标用户

- 想控制体重但经常吃麦当劳的上班族/学生
- 健身人群想在快餐店凑够蛋白质
- 预算有限又想吃好的「穷鬼套餐」爱好者
